# 🌐 Language Translator

A simple desktop app built with Python and Tkinter that translates text between multiple languages using the `googletrans` library.

## Features

- Easy-to-use GUI
- Supports English, Urdu, French, German, Spanish, Hindi and Arabic
- Copy the translated text with one click

## Requirements

- Python 3.7+
- Internet connection

## Installation

```bash
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name
pip install googletrans==4.0.0rc1
python translator.py
```

## Usage

1. Enter your text.
2. Choose the source and target language.
3. Click **Translate**.
4. Click **Copy Text** to copy the result.
